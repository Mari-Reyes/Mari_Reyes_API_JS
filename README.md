# 🇨🇴 Mini Portal de Colombia con API

# Mari_Reyes_API_JS
Sitio web informativo desarrollado con JavaScript, HTML5 y CSS que consume datos en tiempo real desde la [API de Colombia](https://api-colombia.com/). Cuenta con dos vistas independientes conectadas mediante hipervínculos: una sección de datos generales del país y una guía turística con los principales atractivos.

## Tecnologías Usadas
* **HTML5** (Estructura semántica)
* **CSS** (Flexbox, Grid, diseño responsivo)
* **JavaScript** (`fetch`, async/await, manipulación del DOM, manejo de errores)
